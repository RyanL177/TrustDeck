# TrustDeck · 交互原型 Demo

一个演示「AI 演示文稿可信交付检查工具」完整主流程的交互原型，纯前端、零依赖，双击或本地服务器即可运行。

## 一句话说明

> AI 负责生成，TrustDeck 帮你**发现风险、查看依据、完成确认**——最终由你负责地带上场。

本 Demo 演示的是「检查」这一核心环节，而非「生成」：系统对材料做来源标注、一致性检查、风险分级，引导用户逐条确认后导出。

## 运行方式

**方式一：直接打开**

双击 `index.html`，用浏览器打开即可。

**方式二：本地服务器（推荐，体验更完整）**

```bash
cd demo
http-server -c-1
# 访问 http://localhost:8080/index.html
```

## 主流程（五步闭环）

```
1 材料输入 → 2 检查 → 3 风险识别 → 4 人工确认 → 5 导出
```

| 步骤 | 内容 |
|---|---|
| 1 材料输入 | 粘贴文字 / 上传 PPT、PDF / 或一键填充示例 |
| 2 检查 | 解析材料 → 抽取断言 → 标注来源 → 一致性检查 → 风险分级 |
| 3 风险识别 | 左侧预览 + 右侧风险清单 + 顶部「摘要」卡片 |
| 4 人工确认 | 逐条「接受 / 修正 / 忽略 / 确认风险」 |
| 5 导出 | 高风险未处理默认拦截，可「带风险导出」保留标记 |

---

## 核心机制

### 来源三分类

每条关键内容标注来源类型：

- **直接来源**：源材料中原文复现
- **推导**：多条材料整合/计算得出
- **无来源 / 来源不清晰**：无依据或无法追溯

> 来源标注只保证「可追溯」，不保证「正确」。

### 风险三档分级

| 等级 | 判定规则 |
|---|---|
| 高风险 | 精确可证伪的事实数据；或无来源的关键论断；或一致性冲突 |
| 中风险 | 有来源的归纳总结、因果论述、趋势/定性判断 |
| 低风险 | 纯形式内容（标题、排版、措辞） |

### 确认状态机

```
未处理 → 已核验 / 已修正 / 已忽略（仅中低风险）
高风险项：无「忽略」，只有「确认风险后继续」（需二次确认）
```

### 导出控制

- 所有高风险项 ∈ {已核验 / 已修正 / 已确认风险} → 正常导出
- 存在未处理高风险项 → 默认禁止导出，弹出待处理清单
- 有权限用户可选「带风险导出」→ 文件保留风险标记 + 追加「风险与未确认项清单」

---

## 诚实性底线（贯穿全 Demo）

- 界面常驻提示：**「确认表示您已核对并对该内容负责，不保证事实绝对正确」**
- 系统只验证「可检测的一致性与来源状态」，**不证明原始材料真实**，也不替代用户的业务判断
- 不虚构「系统已自动通过」的状态；只如实告知「哪些项无需你操作」

## 真实能力 vs Mock（重要）

| 能力 | 状态 |
|---|---|
| 文件选择 / 拖拽 / 去重 / 移除 | ✅ 真实前端交互 |
| 一致性检查、风险分级、状态机、导出拦截 | ✅ 真实前端逻辑 |
| 文本 / 文件内容解析与生成 | ⚠️ Mock（预置示例数据） |
| 来源类型标注 | ⚠️ Mock（预置标注结果） |
| 多语言输出 | ⚠️ Mock（示例内容） |

> 当前 Demo **未接入任何真实模型或后端 API**。「模拟解析示例文件」按钮、文字「示例材料」按钮产出的都是预置演示数据，真实版本将调用模型解析用户上传的文件与文本。

## 演示路径建议

1. 点击「路演示例（含数据冲突）」→「开始检查」
2. 观察顶部「摘要」卡片：注意「明年市场规模 50 亿」为无来源高风险
3. 直接点「导出」→ 被拦截
4. 逐条处理：接受有据项、修正错误项、对高风险选「确认风险」
5. 全部处理后 → 正常导出；或留一项体验「带风险导出」
6. 回到首页，尝试「模拟解析示例文件」路径（只上传文件、不填文字）
